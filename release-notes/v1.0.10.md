# PawPause v1.0.10

PawPause 1.0.10 is a safety, compatibility, and release-quality update. It makes imported companions safer to manage, restores current Claude Code activity alerts, adds in-app update checks, and refreshes the settings experience.

## Downloads

- **Mac Apple Silicon**: `PawPause-1.0.10-mac-arm64.dmg`
- **Mac Intel**: `PawPause-1.0.10-mac-x64.dmg`
- **Windows 64-bit**: `PawPause-1.0.10-win-x64.exe`

The macOS builds are Developer ID signed, notarized, stapled, and verified by the release workflow.

## What Changed

### Safer companion management

- Added in-app deletion for companions imported directly through PawPause.
- Restricted deletion to the exact PawPause-owned imported companion directory.
- Kept PetDex-managed companions under `~/.codex/pets` read-only to prevent accidental deletion.
- Hardened ZIP imports against path traversal, oversized archives, encrypted entries, unsupported compression methods, and decompression bombs.

### Agent activity improvements

- Restored Claude Code completion detection for current `stop_sequence` session records.
- Kept compatibility with older `end_turn` records.
- Improved the distinction between Claude Code tool activity and final responses.
- Improved Hermes event discovery when Hermes runs in WSL and PawPause runs on Windows.
- Documented Claude Code setup: no extra JavaScript plugin or hook is required.

### Updates and settings

- Added automatic update checks for packaged builds.
- Added a manual **Check for Updates** menu action.
- Added restart/later prompts after an update is downloaded.
- Unified settings navigation, improved smaller-window behavior, and respected reduced-motion preferences.
- Tightened Electron renderer sandbox and content-security defaults.

### Build and release reliability

- Added regression tests for companion deletion, ZIP extraction, and Claude Code log parsing.
- Added pull-request CI for typechecking, tests, desktop builds, and website builds.
- Standardized the repository on Node.js 22 and pnpm 10.33.2.
- Updated direct and transitive dependencies to patched compatible versions.
- Added updater metadata and blockmaps for Windows and both macOS architectures.

## 中文更新摘要

- PawPause 内导入的宠物现在可以安全删除；PetDex 管理的宠物保持只读，避免误删外部文件。
- 加强 ZIP 宠物包校验，防止目录穿越、超大文件、加密条目和解压炸弹。
- 修复新版 Claude Code 的完成提醒，同时兼容旧日志格式；无需安装额外 JS 或 hook。
- 改进 Windows + WSL 环境下的 Hermes 事件监听。
- 新增自动检查更新、手动检查更新，以及下载完成后的重启提示。
- 整理设置页导航、窗口适配和减少动态效果支持。
- 新增删除、ZIP 和 Claude Code 回归测试，并增加 PR CI。
- 锁定 Node.js 22，更新安全依赖和跨平台发布元数据。

## Notes

PawPause remains local-first. Companion packages, settings, reminder history, and coding-agent session detection stay on your machine.
